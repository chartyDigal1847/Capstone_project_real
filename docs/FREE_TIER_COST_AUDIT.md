# Locentra free-tier cost audit

**Reviewed 2026-11-17 against official vendor documentation.** This is a source-code and public-pricing review, not an inspection of account usage, billing settings, or provider consoles. Vendor limits and prices can change; verify them before a trial release.

## Release gates

- Verify the Firebase project is on Spark and that no Cloud Billing account is linked. Do not enable Functions, Vertex/Agent Platform, SMS auth, Cloud Run, or BigQuery streaming.
- Decide whether the no-payment Mapbox trial limits support the chosen map style and 50–100 active users. The satellite toggle currently exposes `satellite-streets-v12`; confirm its raster access before the release workflow depends on it.
- Confirm the Firebase AI Logic provider is Gemini Developer API and keep the Firebase project on Spark. Re-check model free-tier eligibility and data handling before the trial; a later billing association changes the model's pricing tier.
- Measure Firestore read/write/delete counts, Mapbox MAUs and Directions requests, Worker requests/CPU, and whole-account R2 storage/operations in a staging trial.
- Trial Workers are deployed and the signed APK points to the API Worker. Signed-in app workflows and initial R2 reconciliation remain outstanding; the existing Firebase Functions fallback can still require Blaze when `LOCALSPOT_BACKEND_URL` is unset.
