# Locentra trial user guide (draft)

**Not distributable yet.** No signed trial APK exists and there is no trial cloud environment. Do not install the current debug APK as a tester release: it is configured for local Firebase emulators and is not usable outside the development network.

## When the approved trial build is available

1. Obtain the APK from the project maintainer through the agreed private distribution channel. Check its version and SHA-256 against the value provided alongside that release.
2. On Android, allow installation from that trusted distribution source only for the installation, install the APK, then revoke the setting if it is no longer needed.
3. Create an account using the trial's approved sign-up flow and verify your email if prompted. Do not use a production account or reuse a password from another service.
4. Use customer features to browse stores and products. Owner tools appear only for accounts explicitly approved as store owners. Contact the trial administrator if your role appears wrong; do not attempt to bypass it.
5. Store and product images and panorama media may be enabled only after the trial operator confirms successful R2 reconciliation. Uploads count against the shared 9,000,000,000-byte application limit.
6. For a panorama, use a JPEG, allow on-device detection to finish, add manual blur corrections where needed, then inspect all 48 review directions. Automated detection can miss people. Do not approve unless you have personally inspected the full sphere and are satisfied with the derivative.
7. Keep the original panorama private. Do not share downloaded originals. Public panorama viewing is available only after backend verification and owner approval.
8. Report issues through the trial's designated private feedback channel with app version, Android version, approximate time, and steps to reproduce. Never attach passwords, tokens, signing credentials, or private media unless the operator requests it via an approved secure process.
